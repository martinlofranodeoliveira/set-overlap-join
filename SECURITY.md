# Security Policy

## Supported Versions

Only the current main development branch (0.1.0) receives active security review and updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.0   | :white_check_mark: |

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use GitHub Private Vulnerability Reporting at:
https://github.com/martinlofranodeoliveira/set-overlap-join/security/advisories/new

For general non-sensitive contact and company information, please visit the official homepage:
https://lofranotecnologia.com.br
